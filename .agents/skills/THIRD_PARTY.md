# Third-party skills

These skills are copied unchanged from
[mattpocock/skills](https://github.com/mattpocock/skills) at commit
`6f7f7831a625f040a8e06a0e7954826b87ce775a`:

| Skill | Upstream path |
| --- | --- |
| `diagnosing-bugs` | `skills/engineering/diagnosing-bugs` |
| `pr` | `skills/engineering/pr` |
| `grill-me` | `skills/productivity/grill-me` |
| `grilling` | `skills/productivity/grilling` |
| `handoff` | `skills/productivity/handoff` |
| `writing-for-agents` | `skills/productivity/writing-for-agents` |

The `openspec-*` skills are generated by `openspec init` from
[OpenSpec](https://github.com/Fission-AI/OpenSpec) (MIT); `openspec update`
regenerates them and reads `.openspec-target` to know which agents to write
for. To update a copied skill, replace its folder with the
upstream folder at a newer commit, review the diff and update the commit here.
